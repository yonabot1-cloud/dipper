# Dipper — know the moment it dips

Price tracker for Amazon, Walmart, Target, Home Depot, Best Buy, Lowe's, Costco and eBay.

- Accounts (email, optional Google), synced across phone and computer
- Paste a link → photo, name and price are pulled automatically
- Up to 2 years of old prices from free public web archives (Internet Archive + Common Crawl)
- Lowest / highest / average, step chart, monthly averages, "is this a good price?"
- Price alerts as phone/computer notifications (installable home-screen app)

Runs free on Vercel (Hobby) + Supabase (free) + a GitHub Actions schedule.
